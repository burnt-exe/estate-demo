# PropertyOS Interface Wireframes

## Purpose

The prototype demonstrates how an agentic discovery engagement can transition into a complete property operating platform. Every interface uses the same application shell, typography, spacing, cards, metrics, filters, tables, status treatments and responsive breakpoints.

## Interface set

### 1. Executive overview

- Business-value narrative
- Portfolio health metrics
- Eight core capability cards
- 90-day pilot roadmap
- Asset-light revenue model

### 2. Agentic discovery

- Adaptive one-question-at-a-time interview
- Evidence coverage and assessment stages
- Risk-sensitive follow-up questions
- AI or deterministic fallback execution
- Readiness scoring and executive output

### 3. Portfolio operations

- Property and building register
- Location and occupancy visibility
- Monthly billed revenue
- Outstanding operational actions

### 4. Rentals and leasing

- Tenant and unit status
- Rental collection and arrears
- Lease renewal milestones
- Applications and vacancy pipeline

### 5. Maintenance and facilities

- Tenant service requests
- Prioritised work orders
- Contractor allocation
- SLA, approvals and cost control

### 6. Municipal and utilities

- Statement and meter oversight
- Consumption anomaly detection
- Dispute ownership and deadlines
- Validation and audit workflow

### 7. Risk and compliance

- Financial, privacy, legal and operational risk register
- Risk severity
- Control ownership
- Audit evidence and remediation

### 8. Analytics and AI insights

- Net operating income
- Vacancy and maintenance trends
- Forecasting confidence
- AI-recommended management actions

## Responsive behaviour

- Desktop: persistent left navigation and multi-column workspaces
- Tablet: collapsible navigation and reduced grid density
- Mobile: drawer navigation, stacked cards, horizontally scrollable data tables and full-width actions

## Core capabilities demonstrated

1. Adaptive stakeholder discovery
2. Multi-property portfolio management
3. Tenant, rental and lease administration
4. Collections and arrears oversight
5. Maintenance and contractor workflows
6. Municipal and utility assurance
7. Risk, POPIA and control governance
8. Executive analytics and AI recommendations

## Production extensions

- Supabase or Azure SQL persistence
- Entra ID or Supabase authentication
- Organisation and property tenancy model
- Secure stakeholder invitation links
- Cross-stakeholder alignment scoring
- WhatsApp and email workflows
- Payment and accounting integrations
- PDF/DOCX proposal generation
- Audit logging, rate limits and observability
